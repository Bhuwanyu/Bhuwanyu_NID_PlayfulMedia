# **Project: Flower Class Practice — Bhuwanyu Agrawal (2025)**
This small p5.js practice sketch explores the use of classes, object interaction, and simple animation. A custom Flower class is created with functions to draw, move, and change color when the mouse is nearby. Each flower moves around the canvas, bounces off edges, and slightly changes its size over time for a natural swaying effect.

## Features:
- Click to create a new flower at a random position.
- Flowers move independently with slight scaling to mimic growth/sway.
- When the mouse is close to a flower, it changes color to red

## Learnings:
- Using classes and constructors in p5.js.
- Implementing simple animation and interactivity.
- Working with randomness and motion to simulate organic behavior.

## Outcome:
A simple, interactive sketch where animated flowers float and react to mouse proximity—serving as a light, creative exercise in object-oriented programming with the code.
