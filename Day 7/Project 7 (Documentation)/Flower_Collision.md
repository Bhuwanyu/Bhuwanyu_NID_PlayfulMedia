# **Project: Flower Collision (Extended Version)**
This project is an extension of the previous “Flower Using Class” assignment.
It creates an interactive generative animation of multiple flowers that move, grow, change color, and collide dynamically within the canvas.Each flower is represented as an individual object (instance of the Flower class), having its own position, speed, color, and size.

## Features
- A new flower is created every time the mouse is clicked.
- The flower appears at a random position with a random initial velocity.
- Flowers continuously move around the canvas.
- When two flowers come into contact (their radii overlap), they bounce off each other by reversing their velocity directions.
- Flowers also bounce off the canvas edges.
- When the mouse hovers near a flower, it “grows” in size up to a limit.
- Once the mouse moves away, the flower gradually returns to its original size.
- The first time the mouse hovers over a flower, it changes to a random color.

## Additional Enhancement (This Version)
- Each flower now has six petals instead of four, arranged evenly around its center for a fuller look.
- A yellow circular center has been added for visual emphasis.
- The canvas size has been increased to 1980×1080,of average laptop screen size.

## Outcome
The final output is a visually rich, interactive animation where multiple six-petaled flowers drift, collide, and react dynamically to the user’s mouse movements — creating a playful and organic digital garden.
