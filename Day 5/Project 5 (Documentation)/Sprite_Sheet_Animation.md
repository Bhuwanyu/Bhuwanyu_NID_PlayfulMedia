# **Project: 2D Samurai Sprite Animation **

## **Overview**
This project explores 2D sprite animation through the implementation of a free online sprite sheet into a pre-written JavaScript (p5.js) code provided by the professor.
The main goal was to replace the existing sprite sheet from the given code with a newly selected sprite — a Samurai Platformer character — and ensure it functions correctly within the framework.

Beyond successful implementation, additional features and movement controls were introduced to enhance interactivity and responsiveness. A simple day-to-night transition was also added through a background color shift synchronized with a moving sun element.

## **Objective**
- Understand sprite sheet structure and frame sequencing.
- Implement and animate a custom sprite using p5.js.
- Extend interactivity beyond the default controls.
- Introduce an environmental element (day cycle) for atmospheric enhancement.


## **🎮 Character Controls**
**Right Movement Controls →**
- Right Arrow or "D" → Walk Right
- Right Arrow or "D" + Shift → Sprint Right

**Left Movement Controls ←**
- Left Arrow or "A" → Walk Left
- Left Arrow or "A" + Shift → Sprint Left

**Jump Controls**
- Space → Jump in Place
- Right Arrow or "D" + Space → Jump Right

**Attack Controls ⚔️**
- "G" or Left Mouse Click → Sword Attack (Right)

## **Visual Enhancement: Day-Night Cycle **
- An animated ellipse was added to simulate the sun.
- As the sun moves downward and exits the canvas, the background transitions from red to black, visually representing the shift from day to night.
- This feature adds visual storytelling and dynamism to the scene.

## **Art & Design**
- Sprite Art Style: Pixel-based 2D Samurai character.
- Environment Design: Minimalistic background with a gradient transition (sunset to night).
- Animation Direction: Smooth looping animations corresponding to movement states (walk, sprint, jump, attack)
- Color Scheme: Red–to–black gradient emphasizing silhouette and atmosphere.

## **Learning Outcomes**
- Gained understanding of sprite sheet frame handling and animation states.
- Learned how to expand input mappings and implement conditional animation triggers.
- Explored how simple visual cues (like a moving sun) can create environmental storytelling.
